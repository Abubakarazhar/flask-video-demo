# 📹 How to Get a Real Factory Video

## Quick Options:

### Option 1: Download from Free Video Sites (Recommended)

**Pexels (Free, No Attribution Required):**
1. Go to: https://www.pexels.com/search/factory/
2. Or: https://www.pexels.com/search/warehouse/
3. Download any factory/industrial video
4. Save as `factory_video.mp4` in this folder

**Pixabay (Free Videos):**
1. Go to: https://pixabay.com/videos/search/factory/
2. Download a factory video
3. Save as `factory_video.mp4`

### Option 2: Use Your Own Video

Any video showing:
- Factory floor
- Warehouse
- Industrial setting
- Workers
- Machinery

Just upload it through the web interface!

### Option 3: Use YouTube (with youtube-dl)

```bash
# Install youtube-dl first
pip install youtube-dl

# Download a factory video
youtube-dl -f bestvideo[ext=mp4] "YOUTUBE_URL" -o factory_video.mp4
```

## Once You Have a Video:

1. Place it in: `factory_safety_monitoring/factory_video.mp4`
2. Or upload it through the web interface
3. Click "Start Analysis"
4. System will analyze the REAL video!
